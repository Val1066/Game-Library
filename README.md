# Game-Library
Game Library is a web app where users can track games they’ve played, rate and recommend them, and choose their Top 5 favorites. Users can also explore other players’ libraries to discover new games based on their ratings, recommendations, and favorite titles.

# Team Members:
* Kenneth Ly
* Valerie Guillen

# Major Features: 
1. Create an Account 
2. Create a Personal Game Library 
3. Rate and review the game 
4. Recommend games and create a Top 5 Library
5. View other game libraries


# Planned Pages/Screens: 
1. Account Page → Profile, Settings, and Accessibility 
2. Library Page → Person and their Games
3. People Page → People’s Games and Reviews
4. Game Details Page → Game information, ratings, reviews, recommendations, and “add to library”
